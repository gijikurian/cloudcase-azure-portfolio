
# CloudCase

Secure Document Management Platform — Azure Portfolio Project

## Overview

CloudCase is an original ASP.NET Core application
being developed to demonstrate Microsoft Azure
development, DevOps, and cloud architecture skills.

## Current status

- ASP.NET Core Razor Pages application
- Local development prototype
- Cloud infrastructure setup in progress

## Planned Azure technologies

- Azure App Service
- Azure SQL Database
- Azure Blob Storage
- Microsoft Entra ID
- Azure Key Vault
- Azure Monitor
- GitHub Actions
- Bicep Infrastructure as Code

## Running locally

1. Open the CloudCase solution in Visual Studio.
2. Restore NuGet packages if prompted.
3. Run CloudCase.Web using HTTPS.

## Security

This repository uses fictional sample data.
No employer code, customer records, or secrets
are included.
